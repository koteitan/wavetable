フレームパラメータ
0log down TSP: 全倍音が等振幅、高域→低域のチャープ（分散長1600サンプル ≈ 18.1 ms、オクターブ毎に等時間160サンプル）
0–64スペクトラルティルト 0 → −4.8 dB/oct（エネルギーが低次へ集中）
5–31フォルマント F1 (+18 dB)・F2 (+14 dB) がフェードイン
0–256F1: h4→h48 へ上昇 / F2: h500→h16 へ下降（対数スイープ、frame≈208 の h≈30 で交差）
38–115階段ブースト: h3→h1023 を16段の等比ステップ（log2軸で等間隔）で +10 dB、最大倍音まで駆け上がる
159–243偶数次を −26 dB（奇数次のみ = スクエア系へモーフ）
154–256ティルトを −4.8 → −3.0 dB/oct に緩和
全フレームlog down TSP 位相を共通適用 — クレストファクターを 3.2〜4.7 まで低減し、正規化後のRMSをゼロ位相比 +7〜+21 dB 稼ぐ
全フレーム各周期をピーク 0.95 に正規化（full normalize）

A_h(t) [dB] = tilt(t)·log2(h) + F1(t,h) + F2(t,h) + stair(t,h) + even(t,h)。 フォルマントは log2(h) 軸上のガウス形（F1: σ=0.35 oct, F2: σ=0.5 oct）。 位相は log down TSP（群遅延が log2(h) に線形 = オクターブ毎等時間、ESS型）で全フレーム共通。 合成コードは main.js の「DIY synthesis」セクションにあります。
