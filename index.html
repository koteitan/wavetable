フレームパラメータ
0純インパルス: 全倍音が等振幅・ゼロ位相（中央に1本のパルス）
0–64スペクトラルティルト 0 → −4.8 dB/oct（エネルギーが低次へ集中）
5–31フォルマント F1 (+18 dB)・F2 (+14 dB) がフェードイン
0–256F1: h4→h48 へ上昇 / F2: h500→h16 へ下降（対数スイープ、frame≈208 の h≈30 で交差）
38–192低次階段ブースト: h3→h7 を1本ずつ +10 dB
159–243偶数次を −26 dB（奇数次のみ = スクエア系へモーフ）
154–256ティルトを −4.8 → −3.0 dB/oct に緩和
全フレーム各周期をピーク 0.95 に正規化（full normalize）

A_h(t) [dB] = tilt(t)·log2(h) + F1(t,h) + F2(t,h) + stair(t,h) + even(t,h)。 フォルマントは log2(h) 軸上のガウス形（F1: σ=0.35 oct, F2: σ=0.5 oct）。 合成コードは main.js の「DIY synthesis」セクションにあります。
